---
name: list-skills
description: 使用 Demo Menu MCP 列出官方 Skill，讓使用者在聊天選定後直接使用。使用者問有哪些官方流程、要選 Skill 或明確呼叫此入口時使用。
---

1. 呼叫 Demo Menu MCP 的 `list_demo_skills`，按回傳的名稱和用途列出可選流程。只有一個選項時仍要列出並等待選擇。
2. 如果使用者已指定要使用哪個 Skill，就直接繼續。否則問要用哪個 Skill，等使用者選定。使用者可以用名稱或選項編號回答。
3. 選定後，將清單中的 ID 傳給 `get_demo_skill`。讀完回傳的指引後，依使用者的要求執行流程。例如選了「預算配餐」並提供 150 元預算，就呼叫 `list_demo_menu` 並列出符合預算的組合。不知道預算時先問。
4. 使用這次對話的工具和內容完成工作。這個入口不執行安裝指令，也不寫本機 Skill 檔案。使用者另外要求安裝到專案時，再依 README 的安裝方式處理。
